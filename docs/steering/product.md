## Vision

SAT is a web platform for **individual teachers of Chinese** (HSK1–HSK9). A teacher builds curricula
made of lessons — by hand or **generated by AI from the teacher's own PDF/Word material** — opens
classes, enrols students, sets exercise deadlines and follows who has done which exercise. Students
learn the lessons, do auto-graded exercises and exams, review answers and climb a per-class leaderboard.
On top of the class work, **every HV has a class-independent "Tự học" area** (vocabulary with SRS,
Hanzi writing, listening & speaking, HSK mock tests) fed by their GV's own self-study library
(pre-loaded with a starter HSK set, managed by the GV).

## Users

| Role | Who | Device | Top jobs |
|------|-----|--------|----------|
| Giáo viên (GV) | Owner and only admin of one isolated workspace | Desktop web (≥ 1280 px) | Build curricula and lessons (manual or AI), create/activate students, run classes, set deadlines and exams, track done / not done, manage the self-study library ("Kho tự học") |
| Học viên (HV) | Account created by a GV, activated by email | Mobile-first web (360–430 px) | Study lessons, do each exercise set once, take exams, review answers, see rank, profile, Tự học |

Exactly two roles: GV and HV. No super-admin, no centre, no public self-registration in the MVP.

## Content model and rules that shape every module

- **Giáo trình** (one HSK level) → ordered **Bài** → exactly **2 sections: Bài học, Bài tập**. No learning path; exams are not part of a Giáo trình (see Bài thi).
- **Bài thi** (006) stands alone in the GV workspace (own nav item): written by hand with the auto-graded question types of Bài tập, **assigned to one or more classes**, **one schedule per exam** (giờ mở, thời lượng, giờ đóng). Every HV of an assigned class takes it **once**: full duration from start but never past the close time (auto-submit). Score 0–100 shown on submit; answers + explanations only after close. Questions lock once anyone has started.
- **Bài học** = ordered steps made of blocks (từ vựng, ngữ pháp, hội thoại/bài khóa, văn bản, flashcard, tài liệu, video, ảnh, âm thanh). Viewing is **not tracked**.
- **Bài tập** = ordered exercise sets of auto-graded questions: trắc nghiệm (+ vocabulary variants), điền chỗ trống, nối cặp, sắp xếp từ thành câu, viết chữ Hán theo pinyin, đọc hiểu.
- **One attempt per set per class, scored once.** After submitting, the HV always sees own answers + correct answers + explanations. Editing an answer key re-grades after GV confirmation.
- **Lessons are all open**: HV can study every lesson of the course in any order. **Exercise sets are all shown but doable and scored only once the GV has set a deadline** for them in the class (otherwise disabled).
- **Tracking = done / not done per set.** Deadlines are set per set **per class**; late submission allowed and labelled "Nộp muộn"; reminder email at 08:00 on the deadline day to HV who have not submitted.
- **Per-class hide/show** of each section of each Bài. Hidden content disappears for that class's HV; points already earned are kept.
- **Manual editing**: one edit-only screen T07 with tabs Bài học | Bài tập; per-item save. **Student view** (T21) only from the Bài list.
- **AI generation**: T18 right panel (upload PDF/Word + "Mô tả ngắn") → T20 review (Xem trước / Chỉnh sửa per section) → **"Duyệt" = publish and replace** that section (sets with submissions are archived, points kept). Covers ≥ 80 % of the document's knowledge, never above its HSK level. Nothing reaches HV before approval.
- **Accounts**: GV enters HV email (single or Excel) → "Kích hoạt" → system emails a random password. No forced change at first login.
- **Tự học (012–015) is for HV only** and class-independent: every activated HV of the workspace can use it. Content comes from the GV's **Kho tự học** (016, T23–T27): a starter HSK set copied into each workspace, then edited/extended/hidden by the GV. The GV manages but does not use Tự học. HV progress is private, never shown to the GV individually, never part of class ranking or dashboards.
- **Workspace isolation**: another GV's data or a missing item always shows the same "Không tìm thấy nội dung" (A05).

## Domain Glossary

| Term | Meaning |
|------|---------|
| Workspace | All data of one GV |
| Giáo trình | Curriculum for one HSK level, made of Bài |
| Bài | Lesson unit with the 2 sections |
| Bước học / Khối | Learning step / content block in the Bài học section |
| Bộ bài tập | Exercise set in the Bài tập section; one attempt per HV per class |
| Kho nội dung tự học ("Kho tự học" in the GV sidebar) | The GV's per-workspace self-study library (016, T23–T27), seeded from the starter HSK set; feeds the HV Tự học screens S13–S20 |
| Bài thi | Standalone timed exam in the GV workspace, assigned to classes, one schedule; one attempt per HV; score 0–100 |
| Hạn nộp | Per-class deadline of an exercise set (23:59 Vietnam time) |
| Đã làm / Chưa làm / Nộp muộn / Quá hạn | Tracking states of an HV for a set |
| Điểm xếp hạng | Per HV per class: 30% × average exercise-set score + 70% × average exam score (0–100); an item counts once submitted or once its deadline / close time passed (= 0) |
| Duyệt (AI) | GV approval of an AI-generated section = publish + replace |
| Ẩn theo lớp | Section hidden for one class only |

## Product Principles

- Vietnamese UI; Chinese content in simplified Hanzi with tone-marked pinyin; times in Vietnam time (UTC+7).
- Teacher stays in control: AI output never reaches students without explicit approval.
- Simple tracking over analytics: done / not done per set, deadlines, reminders.
- Never lose learning data: anything with submissions is archived or hidden, never deleted.
